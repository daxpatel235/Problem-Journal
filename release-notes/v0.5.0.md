## 📄 Export to PDF

Problem Journal 0.5.0 turns your problems into clean, printable **PDFs**: one problem, a whole folder, a filtered list or your entire journal. Use it to revise before interviews, print a topic, or share your notes.

### What's new

- **Export button in the sidebar.** A new **Export** icon sits at the bottom of the sidebar, just above **Settings**, which is now pinned to the bottom like in VS Code. You can also press `Ctrl+Shift+E`, use **Export…** in the command palette, right-click a folder, or pick **Export as PDF…** from the editor's export menu.
- **Choose what to export.** One problem, any problems you tick, a folder (subfolders included), whatever your problem list's filters show, or everything.
- **Pick problems easily.** A folder tree with checkboxes, plus search and filters for difficulty, topic, tag and favorites. Ticking a folder ticks everything inside it.
- **Save it where you want.** The file name is filled in for you (`Two-Sum.pdf`, `Arrays.pdf`, `Problem-Journal-All.pdf`) and the usual **Save As** window lets you choose the folder.
- **A PDF that reads like your journal.**
  - A4 pages, light theme.
  - Only the fields you filled in, in the same order as the editor.
  - Code last, colored like the editor, with line numbers. Long lines wrap with a ↪ marker.
  - Every problem starts on a new page, and every page has a page number.
  - Exports with several problems get a **title page**, a **contents page** you can click to jump to any problem, and a bookmark for each problem.
  - Hindi notes print correctly on Windows (using its built-in Nirmala UI font). Emoji are left out.
- **Progress you can see.** A progress bar shows how far along the export is, and **Cancel** stops it. When it's done, **Open PDF** and **Show in folder** are one click away.
- **One bad problem doesn't stop the rest.** If a problem can't be exported, the others still are, and you're told which one was left out.
- **Works offline.** The PDF engine is built into the app. It uses half of your CPU cores, so the app stays responsive while it works.

### Removed

- The old **Print / Save as PDF** option. **Export as PDF…** replaces it.

### Upgrading

Just install over your existing version. Your data is kept; there are no database changes in this release.
