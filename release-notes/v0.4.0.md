## 📁 Folders: organize your problems your way

Problem Journal now has a **Folders** view, a file-explorer style screen for grouping problems however you like: by topic, by pattern, by company, or into a "revise before the interview" list.

### What's new

- **New Folders screen.** Click the new **Folders** icon in the sidebar (or open it from the command palette with `Ctrl+K`).
- **Name folders anything.** Emoji and punctuation are fine. Folders can be nested, e.g. `Arrays › Sliding Window`.
- **Rename, move and delete folders.** Deleting a folder also removes its subfolders, but **never deletes your problems**; they stay in *All Problems*.
- **Add Problems in bulk.** Open a folder and pick from all your existing problems with a searchable multi-select.
- **One problem, many folders.** A problem can live in several folders at once.
- **New Problem inside a folder** files the problem there automatically when you first save it.
- **Per-problem actions:** add to another folder, move to another folder, remove from this folder, or move to trash.
- **Full-screen editing.** Clicking a problem in a folder opens it full screen in the editor (autosave included). The **←** back arrow returns you to the folder.
- **Breadcrumb navigation** with back shortcuts: `Alt+←` or `Backspace`.
- **Folders in the editor.** Every problem now shows which folders it's in, with one-click add and remove.
- **Duplicating a problem** puts the copy in the same folders as the original.
- **Fast with large folders.** Big folders load progressively, so they open instantly.

### Changed

- **Windows now ships as an `.msi` installer only.** The NSIS `.exe` setup is no longer built.

### Upgrading

Just install over your existing version. Your data is kept, and the database is upgraded automatically on first launch (it adds the new folder tables; nothing existing is changed).
