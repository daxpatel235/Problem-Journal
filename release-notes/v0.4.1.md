## ⛶ Full-screen code editor

Writing a long solution at the bottom of the problem page was cramped. Problem Journal 0.4.1 adds a **full-screen mode** for the code editor, so you get a whole window to write in, VS Code style.

### What's new

- **Full-screen button.** In the **Code** section, click the new full-screen icon just to the left of the language dropdown. The editor expands to fill the whole window.
- **Back arrow.** A **← Back to problem** arrow in the top-left corner takes you back to the problem page. `Esc` or the minimize icon do the same.
- **Nothing is lost.** Your code, cursor position, scroll position and undo history stay exactly as they were when you switch in and out, and the cursor goes straight back into the editor so you can keep typing.
- **`Esc` behaves sensibly.** It closes the editor's own pop-ups (find, autocomplete) first, and only leaves full screen when nothing else is open.
- **Change language in full screen.** The language dropdown is still there in full screen.

### More platforms

This release adds native builds for **Windows on ARM** and **Linux on ARM**, and an **`.rpm`** package for Fedora, RHEL and openSUSE.

### Upgrading

Just install over your existing version. Your data is kept; there are no database changes in this release.
